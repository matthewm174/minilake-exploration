Pipeline steps — python pipeline\lake.py <step>

all runs every step top to bottom; lake runs all but redshift; any single step can be run on its own. Every step is safe to re-run: catalog objects are created only if missing and Delta tables are overwritten as new versions.

Incremental batch

lake.py land --date 2026-11-14 --seed 8, then bronze, silver, gold, redshift. Bronze re-reads both days; silver resolves overlaps (newest _source_file / updated_at wins); each rewrite is a new Delta version.

Output shape

Each step prints [step] then one line per object, e.g.
lakehouse.silver.orders 598 rows -> s3://acme-lakehouse/silver/orders
