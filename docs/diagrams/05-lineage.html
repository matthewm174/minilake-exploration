landing → bronze

One file glob per table (${LANDING}/orders/*.jsonl), so every landed date is re-read on each run. No filtering — bronze is the audit copy.

bronze → silver

bronze.orders fans out into a header table (orders) and a line table (order_items, via unnest(items)). Both apply the same de-dup and orphan filter so they stay consistent.

silver → gold

All three gold tables join orders ⋈ order_items on order_id. Revenue = completed orders only; product_performance also counts returns and ignores cancelled orders.

gold → Redshift

The loader lists lakehouse.gold from UC, so a new sql/gold/x.sql automatically becomes analytics.x. Each load appends one audit row with the Delta version it read.
